# First 20 Minutes

Goal: create a safe starter brain. Do not try to build the full operating system
on day one.

## Who Runs This

Brain Owner.

## What To Say

```text
I want to set up my company brain. I am the Brain Owner.
```

or:

```text
$brain-owner
```

## What The Agent Should Ask

1. Company name.
2. Where the brain should live.
3. Who should be the Brain Operator.
4. Whether to create a 20-minute starter setup or team pilot setup.
5. Whether to use `governed` or `simple-team`.
6. Whether to write the scaffold after preview.

## What Gets Created

- root routing file
- company brain config
- role guides
- conventions folder
- capture policy
- source registry
- staging queue
- operating schedule
- starter folders and indexes
- `ADD_TO_BRAIN/` and `system/digests/` if `simple-team` is selected

## What Does Not Happen Yet

- no broad connector capture
- no personal account capture
- no automatic source connector capture
- no automatic sensitive or unclear promotion
- no restricted-folder inspection
- no invented company strategy, customer, or team knowledge

## Definition Of Done

The first session is done when:

- setup scaffold exists
- owner knows the next three decisions
- source registry has only defaults/proposed examples
- first schedule is human-gated
- team contribution can begin
