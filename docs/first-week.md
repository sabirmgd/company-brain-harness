# First Week

Goal: move from empty scaffold to useful team memory without losing trust.

## Daily

Brain Operator says:

```text
Run today's company brain check.
```

or:

```text
$brain-operator
```

The agent reports:

- connection status
- source registry warnings
- health score
- lint warnings
- staged proposal queue
- next three actions

## Team Contributions

Each Team Member says:

```text
I want to add what I know to the company brain.
```

or:

```text
$brain-contribute
```

The agent asks about:

- role
- owned decisions and workflows
- docs/SOPs/projects
- stale or wrong knowledge
- source systems used
- what should stay private or restricted

The output is a staged proposal, not a direct final note.

## Owner Reviews

The Brain Owner reviews:

- capture policy
- restricted access
- proposed source instances
- staged notes from the first teammates
- first operating schedule

## End Of Week Check

The first week is successful when:

- at least one owner note is staged or approved
- at least two teammate contributions are staged
- personal sources are still excluded
- source registry is understandable
- operator can run the morning check without developer help
